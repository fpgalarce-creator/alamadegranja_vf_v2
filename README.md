# Alma de Granja (Vite + React + Tailwind)

Base frontend preparada para desarrollo local y despliegue en Vercel.

## Scripts

- `npm run dev`: entorno local con HMR.
- `npm run build`: build de producción en `dist/`.
- `npm run preview`: vista previa del build.

## Estructura

- `src/App.jsx`
- `src/main.jsx`
- `src/components/`
- `src/cart/`
- `src/assets/`

## Deploy en Vercel

El proyecto incluye `vercel.json` con configuración mínima para Vite.
